## Overview
<a id="overview"></a>

Password Checkup is a Chrome extension designed to ensure your online security by checking if any of your passwords have been compromised in data leaks. It targets users who prioritize their online safety and privacy. Utilizing real-time monitoring, Password Checkup alerts you to any potential security threats to your credentials while browsing. Unlike typical password managers, it focuses solely on checking the safety of existing passwords rather than managing them.
